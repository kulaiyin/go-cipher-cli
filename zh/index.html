go-cipher-cliGo CLI 工具

配置管理、结构化日志、交互提示、进度条，并通过 APT 仓库一键分发

快速开始
使用说明

Cobra 命令框架

使用 spf13/cobra 构建，提供 run / version 子命令与完善的帮助系统。

Viper 配置管理

支持 YAML/JSON/TOML 配置文件、环境变量、默认值，可通过 --config 指定路径。

Zap 结构化日志

程序启动即初始化全局 Logger，支持 debug/info/warn/error 多级别。

Survey 交互提示

支持操作类型选择（Encrypt/Decrypt）与目标名称输入。

MPB 进度条

执行任务时实时显示进度，反馈清晰。

APT 仓库分发

通过 GitHub Pages 托管 .deb 与 APT 仓库元数据，客户端 apt install 即可安装。
